# JEXA — AI-Powered Trading Intelligence

![JEXA](https://files.catbox.sh/8wz1v1.png)

**Educational Trading Dashboard** built with Streamlit, yfinance, and LightGBM  
For learning purposes only • Not financial advice

## Features

- AI Daily Signal Scanner (18 US stocks + 8 cryptocurrencies)
- Real-time Backtesting Engine with RSI, MACD, Bollinger Bands
- Risk Management: Stop Loss, Take Profit, Position Sizing
- Beautiful dark UI with candlestick charts
- Discord webhook alerts (optional)

## Live Demo

https://jexa-trading.streamlit.app

## Tech Stack

- Python + Streamlit
- yfinance
- Plotly
- Pandas / NumPy
- LightGBM (AI signals)

## How to Run Locally

```bash
pip install streamlit yfinance plotly pandas numpy
streamlit run streamlit_app.py
```
