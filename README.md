## Features
- Load data from Yahoo Finance, CSV, or Supabase
- Interactive candlestick + multi-indicator overlay
- No-code Strategy Builder (drag-and-drop rules)
- Instant backtesting with CAGR, Sharpe, Max DD
- Equity curve + detailed trade log
- Export professional PDF/HTML reports
- 100% English • Production-ready
